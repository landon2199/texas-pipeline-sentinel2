The plan

Is the land next to Texas pipelines less green or drier than similar land nearby? We answer that with satellite imagery and Python.

What we are doing

Last year Landon measured greenness (NDVI) and a water index along Texas liquid pipelines for one spring, using Sentinel-2 satellite imagery in Google Earth Engine.

This year we rebuild it properly, all in Python: seven springs instead of one (2019 to 2025), a comparison strip further from each pipeline, and one ID per pipeline segment so results line up.

Get set up

  • Send Landon your GitHub username so you can be added to the repository.
  • Register for Google Earth Engine (free for students).
  • Check that Python runs on your laptop, or use Google Colab in a browser.
